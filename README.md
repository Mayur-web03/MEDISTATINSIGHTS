# 🔬 MedistatInsights — AI Malaria Cell Classifier

A deep learning web app that detects malaria-infected blood cells from microscopy images using a CNN trained on the NIH cell image dataset.

## 🚀 Features
- CNN image classifier built with TensorFlow/Keras
- Flask REST API backend
- Drag-and-drop web dashboard

## 🛠️ Tech Stack
TensorFlow · Flask · NumPy · Pillow · HTML/CSS/JS

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python app.py
```
Then open http://localhost:5000

## 📊 Model
The trained model (`malaria-cell-cnn.h5`) is not included due to file size.
